# 子计划 05：文件上传、解析、分类与著录

## 目标

打通外部文件进入档案系统的完整链路，从上传、解析、分类、著录、复核、版本到后续审核和归档。

## 范围

- UploadFile。
- UploadFileVersion。
- FileParser。
- AiClassifier。
- 文件预览。
- 文件替换、重命名、删除。
- 批量著录。
- 人工复核。

## 交付物

- 文件上传入口。
- 文件解析服务接入。
- AI 分类和回退链。
- 著录字段建议。
- 批量确认界面。
- 低置信度复核队列。
- 文件版本链。
- File Cataloguing Agent。

## 关键能力

- 支持 PDF、Word、图片、文本。
- 提取文本、页数、元数据和 OCR 内容。
- 基于 AI 分类、文件名规则和未分类兜底进行分类。
- 推荐目录节点、题名、责任者、编制日期、页数、载体、备注。
- 显示置信度和证据。
- 批量著录前展示影响对象。

## 独立验证

- 上传文件后生成 UploadFile 和 UploadFileVersion。
- 文件解析成功后能查看 extractedText。
- 高置信度文件可批量确认著录。
- 低置信度文件必须人工复核。
- 替换文件后创建新版本，旧版本可追溯。

## 不包含

- 不负责在线表单编制。
- 不负责审核通过。
- 不负责签章和归档包生成。
