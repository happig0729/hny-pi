# 子计划 03：项目立项、单体工程与项目基线

## 目标

打通工程项目从创建到可生产档案的初始化闭环，让项目具备组织、成员、单体、目录和生命周期基线。

## 范围

- Project。
- ProjectExtension。
- Unit。
- UnitExtension。
- ProjectMember。
- Enterprise 关联。
- 项目接入码和邀请机制。
- 项目生命周期基线。

## 交付物

- 项目创建流程。
- 单体工程管理流程。
- 项目成员初始化流程。
- 项目接入码和邀请流程。
- 项目基线生成规则。
- Project Control Agent 的项目初始化能力。

## 关键能力

- 从自然语言或表单创建项目。
- 自动识别缺失项目信息。
- 建议单体工程结构。
- 建议项目成员角色。
- 项目创建后进入目录模板选择。
- 项目锁定或归档后阻断受影响写操作。

## 独立验证

- 创建项目后能看到 Project、ProjectMember、默认生命周期阶段。
- 创建 Unit 后能挂接档案文件和编制实例。
- 项目成员角色影响后续文件、审核、签章、归档动作权限。
- 项目锁定后，编制和上传动作不可执行。

## 不包含

- 不实现目录模板管理。
- 不实现文件上传和归档预检。
