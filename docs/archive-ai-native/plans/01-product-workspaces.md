# 子计划 01：产品壳与工作台信息架构

## 目标

建立完整系统的产品形态。系统主界面不是聊天 demo，而是结构化业务工作台 + 右侧 AI 工作层。

## 范围

- 全局工作台。
- 项目驾驶舱。
- 档案目录树。
- 文件中台。
- 编制工作台。
- 审核工作台。
- 签章工作台。
- 归档工作台。
- 权限审计工作台。
- 右侧常驻 Agent 面板。
- Action Proposal、证据面板、批处理确认区。

## 交付物

- 信息架构图。
- 页面路由结构。
- 通用三栏布局规范。
- 页面级 Agent 匹配表。
- 工作台通用组件清单。
- 高保真原型映射说明，参考 `prototypes/archive-ai-native/index.html`。

## 关键能力

- 用户不用 AI 也能完成关键业务。
- 用户使用 AI 时，AI 直接结合当前页面上下文工作。
- 对话只是入口之一，主要交互是 inline 建议、批量建议、证据面板、Action Proposal。
- 每个工作台都有独立可验证的业务目标。

## 独立验证

- 打开项目驾驶舱，可看到生命周期阶段、阻塞项、下一步建议。
- 打开文件中台，可看到目录树、文件列表、AI 分类和批量著录建议。
- 打开归档工作台，可看到预检结果、阻断问题和整改动作。
- 切换页面时，右侧 Agent 名称、职责、ontology scope 和建议动作随页面变化。

## 不包含

- 不实现底层业务 API。
- 不实现具体 AI 模型调用。
- 不定义业务对象字段细节，字段以 Ontology 为准。
