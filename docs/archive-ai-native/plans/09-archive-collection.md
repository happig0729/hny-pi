# 子计划 09：合规预检、归档包与采集闭环

## 目标

完成工程档案生命周期最后一段：合规预检、问题整改、归档包生成、采集登记、项目或单体归档锁定。

## 范围

- CompliancePrecheck。
- checkProjectArchiveCompleteness。
- validateCityArchiveMapping。
- ArchivePackage。
- CollectedItem。
- Project / Unit 归档锁定。
- 采集类型。
- Archive Agent。

## 交付物

- 预检工作台。
- 缺项检查。
- 目录映射检查。
- 格式和内容风险检查。
- 整改清单。
- 归档包草案和生成。
- 采集记录和去重。
- 锁定/解锁治理。

## 关键能力

- 归档包生成前必须运行预检或记录豁免。
- 预检结果区分阻断、警告、信息。
- 缺项定位到目录节点。
- 映射问题定位到 CityArchiveMapping。
- 采集记录防止重复采集。
- 归档锁定阻断后续编制和上传。

## 独立验证

- 缺少 file 节点档案对象时，完整性检查失败。
- 未完成签章文件不能进入正式归档包。
- 未映射城建节点显示为预检问题。
- 已采集 itemId 再次采集时被阻止或提示重复。
- 项目归档锁定后，写操作被阻断。

## 不包含

- 不实现底层压缩包格式细节。
- 不实现外部档案馆接口。
