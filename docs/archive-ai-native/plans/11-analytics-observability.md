# 子计划 11：统计、监控与运营分析

## 目标

让管理者掌握工程档案生产进度、质量、风险、效率和资源用量，同时让 AI 基于事实层生成可解释运营摘要。

## 范围

- DashboardStats。
- MonthlyTrends。
- ProjectStats。
- TenantStats。
- SealStats。
- StorageStats。
- 逾期、缺项、退回率、签章耗时、归档完成率。
- 运营摘要 Agent 能力。

## 交付物

- 全局仪表盘。
- 项目统计。
- 月度趋势。
- 租户和存储统计。
- 签章统计。
- 风险项目列表。
- AI 运营摘要。

## 关键能力

- 结构化图表作为事实层。
- AI 摘要作为解释层。
- 指标可以追溯到原始对象。
- 异常项目能生成处理建议。

## 独立验证

- Dashboard 能展示项目总数、档案数量、审核状态、签章进度。
- ProjectStats 能展示单项目文件、审核、签章、预检状态。
- 趋势图能按月份展示编制量和审核通过率。
- AI 摘要能引用具体指标和项目。

## 不包含

- 不替代审计系统。
- 不作为业务状态权威来源，业务对象仍是权威。
